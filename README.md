## 👋 Olá! Eu sou Alisson Fluck

**Sobre Mim**

Sou estudante de Big Data e Inteligência Analítica na PUCPR, com foco prático em transição para a área de Engenharia de Dados.

Desenvolvo pipelines de dados estruturados, priorizando a qualidade, a documentação e os fundamentos técnicos. Trabalho na construção de arquiteturas de dados ponta a ponta, desde a ingestão de APIs REST, passando pela limpeza e transformação com a biblioteca Requests e Pandas, até a modelagem analítica com ferramentas de BI.

Meu ambiente de desenvolvimento é focado no ecossistema Linux (WSL), onde também estudo o processamento distribuído com Apache Spark e o ecossistema Hadoop (HDFS, Hive). Sou focado em construir um portfólio que resolva problemas reais de negócio através de dados.
